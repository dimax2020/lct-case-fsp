# Карьера ФСП — фронтенд-прототип

Кликабельный прототип платформы подбора ИТ-специалистов Федерации спортивного программирования. Сделан на Nuxt 4 по макетам и дизайн-системе «Чемпионат России». Бэкенда нет, данные заданы прямо в страницах, а состояние живёт до перезагрузки страницы.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && node .output/server/index.mjs   # прод-сборка (SSR)
npm run generate   # статичная сборка в .output/public — можно положить на любой хостинг
```

Нужен Node.js 20 или новее.

## Что работает

- **Навигация.** Шапка, хлебные крошки, все кнопки-ссылки. В шапке есть меню уведомлений и меню пользователя: профиль, переключение кабинета, выход.
- **Регистрация и вход.**
  - Выбор роли переключает активную карточку.
  - Можно переключаться между регистрацией и входом.
  - Поля проверяются: почта, пароль от 10 символов, согласие на обработку данных.
  - После отправки открывается нужный кабинет в зависимости от роли.
- **Тест на грейд.**
  - 8 заданий, выбор ответа, пропуск.
  - Таймер, прогресс-бар и шкала шагов.
  - После последнего задания открывается страница грейда.
- **Приглашения кандидата.**
  - Список с вкладками, выбор приглашения.
  - «Принять» и «Отклонить» с выбором причины; статусы и счётчики пересчитываются.
- **Подборка работодателя.**
  - Работают фильтры в боковой панели, переключение категорий и вкладки «Подборка / Весь банк / Избранные».
  - Подсказки топ-3 включаются и выключаются, уточнения снимаются кликом.
  - Кандидатов можно добавлять в избранное и приглашать.
- **Приглашение кандидата.** Можно выбрать способ связи; вилка обязательна.
- **Мои приглашения.** Вкладки, напоминание и отзыв приглашения, приглашение на интервью по отклику.
- **Переписка.**
  - Переключение диалогов, поиск по ним.
  - Отправка сообщений, в том числе по Ctrl+Enter.
  - Шаблоны сообщений, предложение времени, выбор слота.
  - «Сделать оффер» и «Завершить без оффера» меняют этап найма.
- **Профили и настройки.**
  - Чипы, чекбоксы и поля ввода редактируются.
  - Загрузка резюме и логотипа компании.
  - В профиле компании превью «Так вас видит кандидат» обновляется сразу.
  - Привязку ФСП ID и согласие на публикацию можно отозвать.
- **Остальные действия.** Скачивание PDF и подобное показывают уведомление-тост.

## Структура

```
app/
  assets/css/tokens.css     токены дизайн-системы (цвета, отступы, срезы, шрифты)
  assets/css/fsp.css        стили компонентов дизайн-системы
  components/fsp/*.vue      компоненты: Button, Input, Chip, Checkbox, Tabs, Header, Plate,
                            StatusBadge, DisciplineBadge, Tag, CompanyLogo, VacancyCard, Icon, Toaster
  composables/useToast.ts   уведомления
  pages/                    экраны (файловый роутинг Nuxt)
public/
  brand/                    логотипы Чемпионата и ФСП
  fonts/                    Inter и Wadik
```

Компоненты подключаются автоматически с префиксом `Fsp`: `<FspButton>`, `<FspChip>` и так далее.

- `FspButton` с `href="/…"` рендерится как `NuxtLink`. Пропс `toast="…"` показывает уведомление по клику.
- `FspChip`, `FspCheckbox`, `FspInput` и `FspTabs` поддерживают `v-model` (у чипа это `v-model:selected`). Без привязки они хранят состояние сами.

## Правила бренда, зашитые в стили

- Синий (`--primary`) — только для того, что можно нажать.
- Фиолетовый (`--accent-mark`) — бейджи дисциплин и выделения.
- Зелёный, жёлтый и красный — только статусы и прогресс.
- Заголовки набраны шрифтом Wadik капсом. Знак ₽ и длинное тире набираются шрифтом Inter.
