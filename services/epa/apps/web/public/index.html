Работодатель Кандидат

Работодатель и кандидат входят по своему имени, без пароля. Работодатель может загрузить свой проект или текст задания. Кандидат открывает свою ссылку на расширение VS Code и отправляет код через git. Дашборд показывает ход работы в открытой папке.

Создайте практику, загрузите проект или ТЗ, пригласите кандидата. Смотрите ход работы, снимки кода, комментарии и отчёт.
