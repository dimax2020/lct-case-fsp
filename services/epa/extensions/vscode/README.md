# EPA — ход работы над заданием

Расширение для кандидата. Оно отправляет работодателю ход работы **только из открытой папки задания**.

## Что сохраняется

- начало и конец сессии в этой папке;
- созданные, изменённые, сохранённые и удалённые файлы и размер правки (без нажатий клавиш);
- команды терминала этой папки, уже без паролей и ключей;
- запуски тестов: команда, сколько прошло и сколько упало;
- коммиты: сообщение, список файлов, короткий идентификатор;
- снимки содержимого папки;
- отметка о крупной вставке кода. Это повод посмотреть внимательнее, а не вывод, что решение списано.

## Что не сохраняется

- клавиши, экран, камера и микрофон;
- буфер обмена вне редактора этой папки;
- другие папки, окна и проекты;
- секреты в командах;
- копирование и вставку в этой папке: файл и объём, без чтения буфера обмена других программ.

## Как пользоваться

1. Скачайте расширение со страницы кандидата и установите: `Cmd+Shift+X` → `…` → **Install from VSIX…**
2. Заберите проект:

```bash
git clone АДРЕС_СО_СТРАНИЦЫ
```

Пароль Git не спросит.

3. Откройте эту папку в VS Code и на странице кандидата нажмите **«Подключить VS Code»**. В окне подтвердите **«Подключить»**. Если окно не открылось, выполните **EPA: Подключить практику** и в адресе укажите только `http://127.0.0.1:8080` — без адреса страницы и без `/v1`.
4. Когда код готов к серверу:

```bash
git add .
git commit -m "что сделано"
git push
```

5. Закройте задачу кнопкой **Закрыть задачу** на странице кандидата. В расширении такой команды нет.

Команда **EPA: Что собирается и чего нет** открывает эту же памятку внутри редактора.
